# Portfolio Redesign Brief

## Goals

- Win freelance conversations.
- Support full-time job applications.
- Build a clear professional identity as a fullstack software developer.
- Make contacting Rizal/Mehmed and downloading the CV the primary actions.

## Audience

- HR and recruiters.
- Prospective freelance clients.
- Software developers and technical peers.

## Identity

- Indonesian display name: Rizal.
- English display name: Mehmed.
- Positioning: Fullstack Software Developer.
- Visual direction: professional, calm, precise, and product-focused.
- Profile image: temporary asset until the final portrait is provided.

## Information Architecture

1. Hero and primary actions.
2. Selected work.
3. Freelance services.
4. Professional experience.
5. Technology stack.
6. About and education.
7. Contact.

## Version 1 Features

- Indonesian and English content with a persistent language preference.
- Responsive navigation and mobile sheet.
- Contact and CV calls to action in the first viewport.
- Selected project evidence with role, technology, and measurable context.
- Freelance services for client visitors.
- Condensed professional experience for recruiters.
- Grouped technology stack for technical visitors.
- Light and dark appearance with a persistent preference.
- Local downloadable PDF CV.
- LinkedIn as the current public contact channel.
- Responsive layout, keyboard focus, semantic landmarks, and reduced-motion support.
- SEO metadata and social sharing metadata.

## Deferred Until Content Is Available

- Contact form: requires a public receiving email or form service.
- GitHub link: requires a confirmed public profile URL.
- WhatsApp action: requires a confirmed business number.
- Live project/repository links: requires confirmed URLs and access status.
- Separate Indonesian and English CV files.
- Final portrait photography.
- Project case-study pages.

## Acceptance Criteria

- `npm run lint` passes.
- `npm run build` passes.
- No horizontal overflow at common mobile and desktop sizes.
- Navigation, language, appearance, contact, and CV controls are keyboard accessible.
- Main content remains understandable without animation.
- All visible content switches language consistently.
- The two primary actions are visible without scrolling on common desktop sizes.
